## 📖 About

This repository gathers small, self-contained Python scripts. Each project lives in its own folder with its own `README.md`, so you can run or reuse any of them independently.

Larger projects that grow beyond a single script are moved to their own repository.

## 📂 Projects

| Project | Description | Run it |
| ------- | ----------- | ------ |
| [`ascii-flower-bouquet`](./ascii-flower-bouquet) | A spinning 3D flower bouquet drawn with text characters, right in your terminal. | `python3 ascii-flower-bouquet.py` |

More scripts coming soon.

## 🚀 Quick start

You only need **Python 3.7 or newer**. Check your version with:

```bash
python3 --version
```

Then clone the repository and run any script:

```bash
git clone https://github.com/ag-hp/python-scripts.git
cd python-scripts/ascii-flower-bouquet
python3 ascii-flower-bouquet.py
```

> [!TIP]
> On Windows, use `python` instead of `python3`.
